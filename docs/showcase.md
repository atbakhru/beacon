# Portfolio showcase

## Repository description
Real-time incident intelligence with Go, Kafka, PostgreSQL/pgvector, Redis, Python embeddings, and a React dashboard. Includes a live interactive demo and reproducible tests.

## A 90-second walkthrough
1. Explain the problem: an outage produces noisy alerts, while responders need one clear incident.
2. Open the live demo and show the 1,200-alert synthetic fixture.
3. Generate a 1,000-alert burst, open the incident, acknowledge it, assign ownership, and resolve it.
4. Show the timeline, related past failures, service health, and duplicate-protection test.
5. Open the architecture and explain the transactional outbox, consumer idempotency, and reconnect snapshot.
6. Point to evidence and clarify the public demo is browser-local; Compose runs the actual backend.

## Accurate project bullet
Built an incident intelligence platform with Go, Kafka, PostgreSQL/pgvector, Redis, and React; implemented transactional alert ingestion, concurrency-safe correlation, incident lifecycle workflows, vector retrieval, and WebSocket updates, with automated integration and browser tests.

Only add measured performance figures with their workload context. Do not claim an AWS deployment or six independently deployed Go services.
